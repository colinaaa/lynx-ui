# Drawer Component Implementation Plan

> **For autonomous workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement a headless Drawer component that pops out from an edge (defaulting to the left side), accompanied by a backdrop overlay, and supports a swipe-to-close gesture utilizing spring physics on the main thread.

**Architecture:** Compound components (`Drawer.Root`, `Drawer.Overlay`, `Drawer.Content`). `Drawer.Root` provides the context and manages the controlled/uncontrolled state. `Drawer.Overlay` displays the backdrop and handles tap-to-close. `Drawer.Content` implements main-thread gesture tracking (MTS) for drag-to-close and spring animations using `@lynx-js/motion/mini`.

**Tech Stack:** ReactLynx, Main Thread Script (MTS), `@lynx-js/lynx-ui-presence`, `@lynx-js/motion`.

### Task 6: Add Gesture support via Main Thread Script (MTS)

**Files:**

- Modify: `packages/lynx-ui-drawer/src/DrawerContent.tsx`

- [ ] **Step 1: Implement MTS bindings for swipe-to-close**
      In `DrawerContent.tsx`, attach `main-thread:bindtouchstart`, `main-thread:bindtouchmove`, and `main-thread:bindtouchend` to the container view.
      Use MTS variables or `useMainThreadRef` to track gesture start X, delta X, and start time.

- [ ] **Step 2: Implement Follow-Finger and Snap**
      On `touch move`, directly update the `transform` style on the main thread (e.g. `transform: translateX(...)`) to follow the finger. Provide spring physics using `@lynx-js/motion/mini` functions or custom JS spring formula.
      On `touch end`, calculate speed and offset. If swiped past a threshold (e.g. 30%), trigger the close animation via MTS, then call `runOnBackground` to update the React state (`onShowChange(false)`). If not, spring back to `translateX(0)`.

- [ ] **Step 3: Commit**
